# Search query rules

The Agent decomposes the topic into `search_concepts` before Python builds Generic Boolean expressions. A group contains alternate names for one concept, joined with `OR`. Distinct groups use `AND`, normally with no more than three groups. A long topic sentence containing multiple concepts is not a default exact phrase. The pipeline removes repeated variants/groups and duplicate expressions; the Agent reviews conceptual equivalence and retrieval breadth. Queries are starting points, so review overly narrow phrase combinations.

`--platform web_of_science` wraps a query in `TS=(...)`; `scopus` uses `TITLE-ABS-KEY(...)`. `google_scholar` retains quoted phrases and `OR` but removes explicit `AND`; Scholar behavior is less precise and should be checked in the UI. `openalex` returns plain search text for the API `search` parameter; it does not claim Boolean compatibility. Generic Boolean output is the canonical representation.

Search expressions support discovery, not proof of term usage. A database hit can match one word or a related topic; inspect title and abstract evidence before making a claim. Exclusions are applied to candidate selection, not automatically encoded as `NOT` operators in every platform.

Static validation checks structure, duplicate groups, long quoted phrases, and abbreviation warnings. Research Mode can sample up to three representative queries using OpenAlex `search`. The executed plain text and API parameters are saved next to the original Boolean expression; they are not equivalent. `retrieval_count` is the provider's count when supplied, `sample_size` is actual returned metadata rows, and `query_coverage` is only sampled lexical group coverage. Without DOI/URL-keyed human relevance labels, `estimated_precision` stays null; with them it is only a labelled-sample fraction. A zero-count probe may remove one AND group at a time, at most twice; zero sampled lexical overlap may add one application-context group. Each variant and result is saved. Do not claim a revised query is better solely from a larger count.
